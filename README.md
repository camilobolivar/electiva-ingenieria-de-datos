En este repositorio se emplean datos de la NASA para el desarrollo de las actividades, análisis y procesos asociados al curso. La estructura del proyecto se organiza en las carpetas artifacts, data, docs, docs (CBL), notebooks y src. Dentro de docs se incluyen las subcarpetas examples y templates, mientras que en src se encuentran los módulos ingest, pipeline y utils, cada uno con su respectiva organización interna. Además, mis documentos personales se almacenan en la carpeta docs (CBL) con el fin de no confundirlos con la carpeta docs creada por el profesor y evitar borrar o modificar por error los ejemplos proporcionados por él.
